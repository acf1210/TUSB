# TUSB v1.0.9

## Português Brasil

- Checagem automática de atualização: ao abrir, o TUSB consulta a última versão publicada (no máximo a cada 12 horas) e avisa quando houver uma nova, com as novidades e um botão para baixar o APK.
- Em Menu → Geral: versão instalada, botão "Verificar agora" e opção para ligar ou desligar a checagem automática.
- Uma versão pode ser ignorada; o TUSB só volta a avisar quando sair a seguinte.

## English US

- Automatic update check: on launch, TUSB checks the latest published version (at most every 12 hours) and lets you know when a new one is out, with the release notes and a button to download the APK.
- Menu → General: installed version, a "Check now" button, and a switch to turn the automatic check on or off.
- A version can be skipped; TUSB only notifies again when the next one is released.

## Español

- Búsqueda automática de actualizaciones: al abrir, TUSB consulta la última versión publicada (como máximo cada 12 horas) y avisa cuando hay una nueva, con las novedades y un botón para descargar el APK.
- En Menú → General: versión instalada, botón "Buscar ahora" y opción para activar o desactivar la búsqueda automática.
- Se puede omitir una versión; TUSB solo vuelve a avisar cuando sale la siguiente.
